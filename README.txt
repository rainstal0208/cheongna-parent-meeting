2027학년도 인천청라고등학교 학부모총회 웹앱 v2

이번 수정
- 공식 학교 로고 적용
- 교사용 제목: '학부모총회 등록부'
- 등록부에서 실제 서명 이미지 표시
- 인쇄/PDF에도 서명 이미지 출력
- 같은 기기에서 다시 '등록하기'를 누르면 중복 등록하지 않음
- 동일 학생+학부모 조합이 이미 있으면 새 레코드를 만들지 않음
- '이미 등록된 학부모입니다' 안내 후 바로 행사 안내 화면으로 이동
- 2026 교실배치도 기준 학급 위치 데이터 반영
- 교사용 '행사 설정' 추가: 1·2·3학년 이동장소를 매 행사마다 직접 변경

주의
- 현재는 브라우저 localStorage 기반 프로토타입입니다.
- 실제 여러 기기 공동 사용에는 Supabase 등 서버 DB 연결이 필요합니다.
- 실제 운영 전 개인정보 동의 문구/보유기간은 학교 내부 기준에 맞춰 확정해야 합니다.

v4 추가 수정
